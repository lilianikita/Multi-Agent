# Артефакт: Проектирование задач (Task Design)
## Источник: Confluence Page ID 2129921 — «Требования ДЗ Лекция 10 #2»
## Версия: v1
## Дата: 2026-11-02

## Дизайн-лог

Группировка требований выполнена по функциональным модулям системы:

1. **Аутентификация и профиль** — объединены регистрация, авторизация, блокировка, восстановление доступа, профиль и адреса (тесно связанные функции одного модуля)
2. **История заказов** — выделена отдельно из-за специфической логики «повтор в один клик»
3. **Каталог и поиск** — единый модуль каталога с поиском, сортировкой и карточкой товара
4. **Корзина** — самостоятельный модуль с расчетами и заменами
5. **Оформление заказа** — воркфлоу чекаута с выбором адреса, времени, оплаты
6. **Доставка и логистика** — трекинг, уведомления, контроль сборки
7. **Административная панель** — отдельный модуль для сотрудников
