## 1. Синтез

Требования описывают интернет-магазин продуктов с доставкой: регистрация и личный кабинет, каталог и поиск, корзина, оформление и оплата заказа, доставка с отслеживанием, административная панель магазина.

## 2. Функциональные требования (37)

### 1. Регистрация, авторизация и профиль (FR-AUTH)

| ID | Требование |
|---|---|
| FR-AUTH-01 | Регистрация по номеру телефона с подтверждением через SMS-код |
| FR-AUTH-02 | Регистрация через email |
| FR-AUTH-03 | Авторизация по номеру телефона/паролю или email/паролю |
| FR-AUTH-04 | Восстановление доступа: сброс пароля через SMS или ссылку на email |
| FR-AUTH-05 | Личный кабинет: просмотр и редактирование профиля (имя, дата рождения, адреса доставки, сохранённые банковские карты) |
| FR-AUTH-06 | История заказов: список всех выполненных заказов с повтором в один клик |
| FR-AUTH-07 | Управление адресами: несколько адресов (дом, работа, дача), назначение адреса по умолчанию |

### 2. Каталог товаров и поиск (FR-CAT)

| ID | Требование |
|---|---|
| FR-CAT-01 | Главная страница: баннеры с акциями, категории (овощи, молочная продукция, мясо, напитки), блок «Хиты продаж» |
| FR-CAT-02 | Листинг товаров в виде плитки или списка |
| FR-CAT-03 | Сортировка: по цене, по популярности, по рейтингу |
| FR-CAT-04 | Фильтры: бренд, цена, жирность, вес, наличие скидки |
| FR-CAT-05 | Поиск по названию товара, категории или бренду |
| FR-CAT-06 | Подсказки при вводе первых трёх букв |
| FR-CAT-07 | Обработка опечаток (пример: «марковь» → «морковь») |
| FR-CAT-08 | Карточка товара: основное фото, галерея, вес/объём, цена за единицу (кг/шт), состав, КБЖУ, срок годности, рейтинг, отзывы |
| FR-CAT-09 | Карточка товара: кнопка «Добавить в корзину» |
| FR-CAT-10 | Акции и спецпредложения, сезонные коллекции («Всё для шашлыка», «Постные продукты») |

### 3. Работа с корзиной (FR-CART)

| ID | Требование |
|---|---|
| FR-CART-01 | Добавление товаров, изменение количества (шт, кг), удаление позиций |
| FR-CART-02 | Автоматический пересчёт итоговой суммы при изменении количества |
| FR-CART-03 | Информирование и блокировка перехода к оформлению, если сумма меньше минимальной для адреса |
| FR-CART-04 | Замены: опция «Разрешать замену» и предложение 2–3 аналогичных товаров при отсутствии товара |
| FR-CART-05 | Промокоды: ввод с мгновенным применением скидки и отображением новой итоговой суммы |

### 4. Оформление заказа (FR-CHK)

| ID | Требование |
|---|---|
| FR-CHK-01 | Выбор адреса из сохранённых или ввод нового с автоматическим определением зоны и доступного интервала |
| FR-CHK-02 | Выбор двухчасового интервала доставки или опции «доставить как можно скорее» |
| FR-CHK-03 | Способы оплаты: на сайте (карта, СБП, SberPay), курьеру картой через терминал или наличными |
| FR-CHK-04 | Комментарий к заказу и комментарий к конкретному товару для сборщика |
| FR-CHK-05 | Экран подтверждения с составом заказа, адресом, временем и стоимостью перед оплатой |

### 5. Доставка и логистика (FR-DLV)

| ID | Требование |
|---|---|
| FR-DLV-01 | Отслеживание статуса заказа: «Принят», «Собирается», «Передан курьеру», «Доставлен» |
| FR-DLV-02 | Карта с местоположением курьера в реальном времени |
| FR-DLV-03 | Автоматические Push-уведомления или SMS при смене статуса заказа |
| FR-DLV-04 | Фотография собранного заказа, отправляемая пользователю перед выездом курьера |

### 6. Административная панель (FR-ADM)

| ID | Требование |
|---|---|
| FR-ADM-01 | Управление товарами: добавление, редактирование, удаление, загрузка фотографий |
| FR-ADM-02 | Управление остатками на складе с автоматическим резервированием при оформлении заказа |
| FR-ADM-03 | Управление заказами: просмотр новых, передача в сборку, ручное изменение статуса |
| FR-ADM-04 | Управление курьерами: назначение заказов, отслеживание маршрутов на карте |
| FR-ADM-05 | Управление пользователями: просмотр профилей клиентов, блокировка аккаунтов |
| FR-ADM-06 | Аналитика: отчёты по продажам, популярным товарам и среднему чеку |

## 3. Бизнес-правила (4)

| ID | Правило |
|---|---|
| BR-AUTH-01 | IF 5 неудачных попыток ввода пароля THEN блокировать доступ на 15 минут |
| BR-CAT-01 | Цена со скидкой рассчитывается автоматически; отображаются перечёркнутая старая цена и счётчик времени до конца акции |
| BR-CART-01 | IF сумма заказа < минимальной суммы для выбранного адреса THEN информировать AND блокировать переход к оформлению |
| BR-ADM-01 | IF заказ оформлен THEN остаток товара резервируется автоматически |

## 4. Ограничения (из текста)

- CON-01: подтверждение номера телефона при регистрации выполняется через SMS-код.
- CON-02: дата рождения используется для проверки возраста при покупке алкоголя.
- CON-03: минимальная сумма заказа зависит от выбранного адреса.
- CON-04: доступный интервал доставки определяется зоной доставки адреса.

## 6. Зависимости

| Зависимость | Обоснование |
|---|---|
| FR-AUTH-01/02 → FR-AUTH-04 | Восстановление доступа требует существующего аккаунта |
| FR-AUTH-03 → FR-AUTH-05/06/07 | Личный кабинет доступен только после входа |
| FR-CAT-01…10 → FR-CART-01/02 | Корзина работает с товарами каталога |
| FR-CART-05 → FR-CHK-05 | Итоговая сумма с промокодом фиксируется на экране подтверждения |
| FR-CHK-01 → FR-CHK-02 | Доступные интервалы зависят от зоны доставки адреса |
| FR-CHK-05 → FR-DLV-01 | Статусы появляются только после создания заказа |
| FR-ADM-01 → FR-CAT-08 | Карточка товара отображает данные, введённые в админ-панели |
| FR-ADM-02 → FR-CART-03/FR-CHK | Резерв остатка выполняется при оформлении заказа |
| FR-ADM-04 → FR-DLV-02 | Карта курьера использует маршруты из админ-панели |

## 7. Неоднозначности (14)

| ID | Место | Проблема |
|---|---|---|
| AMB-01 | Корзина, минимальная сумма | Порог «например, 1000 рублей» не утверждён; нет значений по зонам и правил округления |
| AMB-02 | Корзина, замены | Не определено, кто и по какому алгоритму подбирает 2–3 аналога |
| AMB-03 | Поиск, подсказки | Не определено, что считается «буквой», сколько подсказок и по каким полям |
| AMB-04 | Поиск, опечатки | Не задан допустимый порог опечаток и поведение при отсутствии результатов |
| AMB-05 | Фильтры | Поведение фильтра «жирность» для категорий без жирности |
| AMB-06 | Акции | Часовой пояс таймера и поведение цены после окончания акции |
| AMB-07 | Карта курьера | Частота обновления координат и точность |
| AMB-08 | «Доставить как можно скорее» | Не задан SLA режима и поведение при отсутствии слотов |
| AMB-09 | Фото заказа | Формат, размер, срок хранения, доступ после доставки |
| AMB-10 | Блокировка входа | Считается по аккаунту, IP или устройству; когда сбрасывается счётчик |
| AMB-11 | «Хиты продаж» | Алгоритм и период формирования блока |
| AMB-12 | Аналитика | Период и формула расчёта среднего чека |
| AMB-13 | Листинг | Как переключаются плитка/список и какой вид по умолчанию |
| AMB-14 | Карточка товара | Источник рейтинга и правила модерации отзывов |

## 10. Риски

- R-01: отсутствие НФТ блокирует оценку производительности карты курьера и поиска.
- R-02: автоматическое резервирование остатков без правил снятия резерва ведёт к «зависшим» остаткам.
- R-03: хранение банковских карт без требований соответствия создаёт регуляторный риск.
- R-04: подбор аналогов и обработка опечаток требуют отдельного сервиса/алгоритма — возможен выход за оценку.
- R-05: интеграции SMS/Push, платежей и картографии не описаны — риск внешних зависимостей.
- R-06: единая админ-панель без ролей создаёт риск избыточных прав сотрудников.
- R-07: возрастная проверка при продаже алкоголя без утверждённых правил создаёт юридический риск.
