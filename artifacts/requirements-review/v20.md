## 1. Синтез

Требования описывают интернет-магазин продуктов с доставкой: клиентский контур (регистрация и профиль, каталог и поиск, корзина, оформление заказа, доставка и отслеживание) и служебный контур (административная панель магазина). Основная цель — обеспечить полный цикл заказа продуктов онлайн с оплатой, доставкой и операционным управлением ассортиментом, заказами и курьерами.

## 3. Функциональные требования

### 3.1 Регистрация, авторизация и профиль

| ID | Требование |
|---|---|
| REQ-01 | Создание аккаунта по номеру телефона с подтверждением SMS-кодом или через email |
| REQ-03 | Вход в личный кабинет по номеру телефона/паролю или email/паролю |
| REQ-04 | Блокировка доступа после 5 неудачных попыток ввода пароля на 15 минут |
| REQ-05 | Сброс пароля через SMS или ссылку на email |
| REQ-06 | Просмотр и редактирование профиля: имя, дата рождения, адреса доставки, сохранённые банковские карты |
| REQ-07 | История заказов с повторением заказа в один клик |
| REQ-08 | Несколько адресов доставки и назначение адреса по умолчанию |

### 3.2 Каталог товаров и поиск

| ID | Требование |
|---|---|
| REQ-09 | Главная страница: баннеры акций, категории (овощи, молочная продукция, мясо, напитки), блок «Хиты продаж» |
| REQ-10 | Листинг товаров в категории в виде плитки или списка |
| REQ-11 | Сортировка (цена, популярность, рейтинг) и фильтры (бренд, цена, жирность, вес, наличие скидки) |
| REQ-12 | Поиск по названию товара, категории или бренду |
| REQ-13 | Подсказки при вводе первых трёх букв |
| REQ-14 | Обработка опечаток («марковь» → «морковь») |
| REQ-15 | Карточка товара: основное фото, галерея, вес/объём, цена за единицу, состав, КБЖУ, срок годности, рейтинг, отзывы |
| REQ-16 | Кнопка «Добавить в корзину» |
| REQ-17 | Акции: авторасчёт цены со скидкой, перечёркнутая старая цена, счётчик времени до конца акции |
| REQ-18 | Сезонные коллекции — отдельный раздел тематических подборок |

### 3.3 Корзина

| ID | Требование |
|---|---|
| REQ-20 | Изменение количества товара (шт, кг) и удаление позиций |
| REQ-21 | Автоматический пересчёт итоговой суммы при изменении количества |
| REQ-22 | Информирование и блокировка перехода к оформлению при сумме ниже минимальной |
| REQ-24 | При отсутствии товара — опция «Разрешать замену» и предложение 2–3 аналогичных товаров |
| REQ-25 | Поле промокода с мгновенным применением скидки и отображением новой итоговой суммы |

### 3.4 Оформление заказа

| ID | Требование |
|---|---|
| REQ-26 | Выбор сохранённого адреса или ввод нового с определением зоны доставки и доступного интервала |
| REQ-27 | Выбор двухчасового интервала доставки или опции «доставить как можно скорее» |
| REQ-28 | Способы оплаты: на сайте (карта, СБП, SberPay), курьеру картой через терминал или наличными |
| REQ-29 | При отказе платежа, таймауте и недоступности провайдера — сообщение об ошибке, заказ останавливается |
| REQ-30 | Комментарий к заказу и комментарий к конкретному товару для сборщика |
| REQ-31 | Экран итоговой проверки состава заказа, адреса, времени и стоимости перед оплатой |

### 3.5 Доставка и логистика

| ID | Требование |
|---|---|
| REQ-32 | Зоны доставки: Москва в пределах МКАД — бесплатно, за пределами МКАД — 200 руб. |
| REQ-33 | Отслеживание статуса («Принят», «Собирается», «Передан курьеру», «Доставлен») и карта с местоположением курьера в реальном времени |
| REQ-34 | Автоматическая отправка SMS при смене статуса заказа |
| REQ-35 | Фотография собранного заказа отправляется пользователю перед выездом курьера |

### 3.6 Административная панель

| ID | Требование |
|---|---|
| REQ-36 | Управление товарами: добавление, редактирование, удаление, загрузка фото, управление остатками с автоматическим резервированием при оформлении |
| REQ-37 | Управление заказами: просмотр новых, передача в сборку, ручное изменение статуса |
| REQ-38 | Управление курьерами: назначение заказов, отслеживание маршрутов на карте |
| REQ-39 | Управление пользователями: просмотр профилей клиентов, блокировка аккаунтов |
| REQ-40 | Аналитика: отчёты по продажам, популярным товарам и среднему чеку |

## 4. Бизнес-правила

| ID | Правило |
|---|---|
| BR-01 | 5 неудачных попыток ввода пароля → блокировка доступа на 15 минут (REQ-04) |
| BR-02 | Сумма заказа < 500 руб. → информирование и блокировка оформления (REQ-22, REQ-23) |
| BR-03 | Отсутствие товара → предложение опции «Разрешать замену» и 2–3 аналогов (REQ-24) |
| BR-04 | Адрес в пределах МКАД → доставка 0 руб.; за пределами МКАД → 200 руб. (REQ-32) |
| BR-05 | Отказ платежа / таймаут / недоступность провайдера → ошибка и остановка заказа (REQ-29) |
| BR-06 | Оформление заказа → автоматическое резервирование остатка на складе (REQ-36) |
| BR-07 | Адрес по умолчанию из профиля подставляется при оформлении заказа (REQ-08) |

## 5. Ограничения

| ID | Ограничение |
|---|---|
| CON-01 | Алкогольная продукция не входит в ассортимент магазина (REQ-19) |
| CON-02 | Минимальная сумма заказа — 500 руб. (REQ-23) |
| CON-03 | Тариф доставки за пределами МКАД фиксирован — 200 руб. (REQ-32) |
| CON-04 | Перечень поддерживаемых способов оплаты ограничен: карта, СБП, SberPay, терминал у курьера, наличные (REQ-28) |
| CON-05 | Перечень статусов заказа ограничен четырьмя значениями (REQ-33) |
| CON-06 | Перечень категорий каталога задан явно: овощи, молочная продукция, мясо, напитки (REQ-09) |

## 6. Критерии приёмки (сводно)

| AC-08 | При смене статуса заказа отправляется SMS |
| AC-09 | Остаток товара резервируется при оформлении заказа |
