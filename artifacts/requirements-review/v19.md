## Quality Gate

Проверяемые критерии: атомарность, тестируемость, непротиворечивость, полнота обязательных параметров, трассируемость.

| Критерий | Оценка |
|---|---|
| Атомарность | Все пункты сегментированы по разделам; составные пункты разбиты на отдельные проверки |
| Тестируемость | Каждый принятый пункт имеет наблюдаемое поведение и тест |
| Непротиворечивость | Противоречий между разделами не выявлено |
| Полнота параметров | Критические параметры заданы (500 руб., 5 попыток/15 мин, 200 руб. за МКАД, статусы, способы оплаты) |
| Трассируемость | REQ -> KAN -> тест-кейс Testomat, связи созданы |
