## 3. Бизнес-правила

| ID | Правило | Определено в источнике |
|---|---|---|

## 4. Quality Gate

Проверки: полнота, однозначность, тестируемость, непротиворечивость, отсутствие внешних знаний.

| # | Проверка | Итог |
|---|---|---|
| 1 | Полнота (все ли ветки описаны) | FAIL |
| 2 | Однозначность формулировок | FAIL |
| 3 | Тестируемость (есть ли измеримые критерии) | PASS (32/32 REQ имеют проверяемое поведение) |
| 4 | Непротиворечивость | PASS |
| 5 | Отсутствие внешних заимствований | PASS |

**Вердикт: FAIL**

Blocking items:
1. BR-03: не задано значение минимальной суммы и справочник значений по зонам доставки — требование REQ-17 нереализуемо в общем виде.
2. BR-05: не сформулировано правило проверки возраста при продаже алкоголя (только упоминание даты рождения) — REQ-06 частично нереализуемо.
3. Отсутствует описание обработки ошибки/отказа платежа, отмены и возврата заказа — REQ-22 и REQ-24 неполны.
4. Не определены роли и права доступа сотрудников административной панели — REQ-28…REQ-32 нереализуемы по правам.

Неблокирующие пробелы (в Open Questions): политика пароля и SMS-провайдер, хранение карт, критерий «Хиты продаж», алгоритм опечаток, правила подбора аналогов, правила интервалов доставки, канал уведомлений, методика среднего чека.
