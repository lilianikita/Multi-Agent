## 1. Синтез

Требования описывают интернет-магазин продуктов с доставкой: клиентский контур (регистрация и профиль, каталог и поиск, корзина, оформление заказа, доставка и отслеживание) и служебный контур (административная панель магазина). Основная цель — обеспечить полный цикл заказа продуктов онлайн с оплатой, доставкой и операционным управлением ассортиментом, заказами и курьерами.

## 3. Функциональные требования

### 3.1 Регистрация, авторизация и профиль

| ID | Требование |
|---|---|
| REQ-01 | Создание аккаунта по номеру телефона с подтверждением SMS-кодом или через email |
| REQ-03 | Вход в личный кабинет по номеру телефона/паролю или email/паролю |
| REQ-04 | Блокировка доступа после 5 неудачных попыток ввода пароля на 15 минут |
| REQ-05 | Сброс пароля через SMS или ссылку на email |
| REQ-06 | Просмотр и редактирование профиля: имя, дата рождения, адреса доставки, сохранённые банковские карты |
| REQ-07 | История заказов с повторением заказа в один клик |
| REQ-08 | Несколько адресов доставки и назначение адреса по умолчанию |

| REQ-10 | Листинг товаров в категории в виде плитки или списка |

| ID | Требование |

## 4. Бизнес-правила

| ID | Правило |
|---|---|
| BR-01 | 5 неудачных попыток ввода пароля → блокировка доступа на 15 минут (REQ-04) |
| BR-02 | Сумма заказа < 500 руб. → информирование и блокировка оформления (REQ-22, REQ-23) |
| BR-03 | Отсутствие товара → предложение опции «Разрешать замену» и 2–3 аналогов (REQ-24) |
| BR-04 | Адрес в пределах МКАД → доставка 0 руб.; за пределами МКАД → 200 руб. (REQ-32) |
| BR-05 | Отказ платежа / таймаут / недоступность провайдера → ошибка и остановка заказа (REQ-29) |
| BR-06 | Оформление заказа → автоматическое резервирование остатка на складе (REQ-36) |
| BR-07 | Адрес по умолчанию из профиля подставляется при оформлении заказа (REQ-08) |
