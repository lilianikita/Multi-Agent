## Бизнес-правила

| ID | Правило | Проверяемость |
|---|---|---|
| BR-01 | 5 неудачных попыток → блокировка на 15 минут | Проверяемо: оба значения заданы |
| BR-02 | Сумма меньше минимальной для адреса → информирование и блокировка оформления; минимум 500 руб. | Частично: конфликт «для адреса» ↔ фиксированные 500 руб. |
| BR-03 | Нет товара → опция «Разрешать замену» и 2–3 аналога | Частично: критерий аналогичности не задан |
| BR-04 | Остаток резервируется автоматически при оформлении | Частично: момент снятия резерва не задан |
| BR-05 | Дата рождения используется для проверки возраста при покупке алкоголя | Конфликтует с REQ-25 |
| BR-06 | Статусная модель: «Принят» → «Собирается» → «Передан курьеру» → «Доставлен» | Частично: переходы и роли не заданы |
| BR-07 | Отказ платежа / таймаут / недоступность провайдера → ошибка, заказ остановлен | Проверяемо на уровне поведения |
| BR-08 | Доставка: в пределах МКАД бесплатно, за МКАД 200 руб. | Проверяемо |
