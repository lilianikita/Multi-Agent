## 3. Формат шагов

Все кейсы описаны в Given-When-Then, шаги атомарные, тестовые данные — плейсхолдеры (`{phone}`, `{sms_code}`, `{promo_code}`, `{min_order_sum}` и т.д.), без «магических» значений.

Пример (`e94e1236`):

```
**Given** Выбран адрес {address} с минимальной суммой {min_order_sum}
**And** Сумма корзины {cart_sum} меньше {min_order_sum}
**When** Пользователь открывает корзину
**Then** Отображается предупреждение о минимальной сумме
**And** Переход к оформлению заблокирован
```
